# Calculator
## Description
A web-based calculator built using HTML, CSS, and JavaScript. Users can perform basic arithmetic operations with a clean and responsive interface.

## Features
- Perform addition, subtraction, multiplication, division, and percentage calculations.
- Clear input with "AC" and delete last entry with "DEL".
- Supports decimal numbers and double zero "00" input.
- Responsive and user-friendly interface for quick calculations.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Tools: VS Code, Git & GitHub
